\section{\MakeUppercase{3. Does it generalise?}}

\lead{Every dataset is scored against a \emph{matched} control: same encoders,
same split, ordinary BCE training. It repeats the pattern on all seven,
\hlw{pooled AUC 0.84--0.98} at near-chance ranking. The prior is as skewed
on all seven (concentration $\approx$ 0.995), so this is not specific to
BRENDA-200.}
